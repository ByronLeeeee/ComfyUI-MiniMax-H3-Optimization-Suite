# Third-party notices and references

This repository does not bundle MiniMax H3 model weights, ComfyUI,
SageAttention, Triton, PyTorch, comfy-kitchen, or ComfyUI-KJNodes.

The CAB sampler is an independent adaptation of the published Corrected
Adams-Bashforth equations to ComfyUI's denoised-output convention and MiniMax
H3's packed audio/video latent type. Reference materials:

- Paper: <https://arxiv.org/abs/2605.16736>
- Official implementation: <https://github.com/Anuska-Roy/CAB>

Third-party projects and model files retain their own licenses and terms. The
MIT license in this repository applies only to the code and documentation
distributed here.
